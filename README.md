Windows endpoint, KQL rules written against simulated ATT&CK techniques, every investigation
documented start to finish. So far I've worked on memory and disk forensics, network and wireless
intrusion detection, and pulling IOCs out of a memory image with Python. I've got an MEng in Computer
Science (2:1) from Southampton, and eight years before that in customer-facing work — high volume,
constant pressure, and a lot of explaining things clearly to people who needed an answer.
